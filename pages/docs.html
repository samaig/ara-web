Core Concepts

What is Araviel?

Araviel is an AI orchestration platform that automatically routes your queries to the best AI model for the task. Instead of choosing between ChatGPT, Claude, Gemini, or other models, Araviel's Decision Engine (ADE) analyzes your query and selects the optimal model instantly.

The Araviel Decision Engine (ADE)

ADE is our proprietary routing system that:

  • Analyzes your query intent, complexity, and requirements
  • Evaluates available AI models based on their strengths
  • Routes your query to the optimal model in real-time
  • Learns from feedback to improve future routing decisions

Supported AI Models

Araviel integrates with leading AI providers:

  • OpenAI: GPT-4, GPT-4 Turbo, GPT-3.5
  • Anthropic: Claude 3 Opus, Claude 3 Sonnet, Claude 3 Haiku
  • Google: Gemini Pro, Gemini Ultra
  • Meta: Llama 2, Llama 3
  • Mistral: Mistral Large, Mistral Medium

Best Practices

Writing Effective Prompts

  • Be specific: Clear, detailed queries get better results
  • Provide context: Include relevant background information
  • State your goal: Explain what you want to achieve
  • Iterate: Refine your query based on initial responses

Optimizing ADE Routing

  • ADE works best with natural language queries
  • Don't try to "game" the system by mentioning model names
  • Trust ADE's decisions - it's trained on millions of routing decisions
  • Provide feedback using the thumbs up/down buttons to improve routing

Managing Conversations

  • Use descriptive titles for easy retrieval
  • Archive old conversations to keep your dashboard clean
  • Export important conversations for backup
  • Use folders (Team plan) to organize by project

Security and Privacy

  • Never share sensitive credentials or personal data in queries
  • Use Private Mode for confidential conversations (deleted after session)
  • Review our Privacy Policy for data handling practices
  • Enable 2FA in account settings for added security

Troubleshooting

Common Issues

Slow Response Times

  • Check the System Status page for outages
  • Some models are slower than others - ADE balances speed and quality
  • Very long queries may take longer to process
  • Try refreshing your browser or clearing cache

Unexpected Model Selection

  • ADE considers many factors beyond query content
  • Model availability and performance metrics affect routing
  • Provide feedback to help ADE learn your preferences
  • You can manually override ADE in Settings (Pro/Team plans)

Conversation History Not Saving

  • Ensure you're logged in (not using guest mode)
  • Check that Private Mode is not enabled
  • Verify your subscription is active
  • Contact Support if the issue persists

API Errors

  • Verify your API key is valid and not expired
  • Check rate limits for your plan
  • See the API Reference for error codes
  • Test your integration with our sandbox environment

Frequently Asked Questions

How does ADE decide which model to use?

ADE uses a combination of natural language processing, query classification, and real-time model performance data to route each query to the optimal AI model. It considers factors like task type, complexity, context length, and model availability.

Can I choose which model to use?

Pro and Team plan users can set model preferences or manually select models. However, we recommend letting ADE handle routing for optimal results.

Is my data used to train AI models?

No. Your conversations are private and not used to train third-party AI models unless you explicitly opt in. See our Privacy Policy for details.

Can I use Araviel for commercial projects?

Yes! All paid plans include commercial use. Team plans are designed specifically for businesses and include API access for integration into your products.

What happens if a model is unavailable?

ADE automatically fails over to the next best model. You'll be notified if routing was affected by availability issues.

We offer prorated refunds within 30 days of subscription purchase. See our Terms of Service for details.
