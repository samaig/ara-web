Getting Started

Authentication

All API requests require authentication using an API key. Include your API key in the request header:

Authorization: Bearer YOUR_API_KEY

Get Your API Key

  1. Log in to your Araviel account
  2. Navigate to Settings → API
  3. Click "Generate New API Key"
  4. Copy and securely store your key (it won't be shown again)

Note: API access requires a Pro or Team plan.

Base URL

https://api.araviel.ai/v1

Rate Limits

  • Pro Plan: 10,000 requests/month (100 requests/minute)
  • Team Plan: 50,000 requests/month (200 requests/minute)
  • Enterprise: Custom limits (contact sales)

Rate limit headers are included in every response:

X-RateLimit-Limit: 100
X-RateLimit-Remaining: 95
X-RateLimit-Reset: 1698765432

Chat Completions

POST /chat/completions

Create a chat completion with automatic model routing via ADE.

Request Body

{
  "messages": [
    {
      "role": "user",
      "content": "Write a Python function to calculate fibonacci numbers"
    }
  ],
  "temperature": 0.7,
  "max_tokens": 1000,
  "stream": false
}

Parameters

Parameter Type Required Description
messages array Yes Array of message objects with role and content
temperature number No Sampling temperature (0-2). Default: 0.7
max_tokens integer No Maximum tokens to generate. Default: 1000
stream boolean No Enable streaming responses. Default: false
model string No Override ADE and specify a model. Default: auto

Response

{
  "id": "chatcmpl-abc123",
  "object": "chat.completion",
  "created": 1698765432,
  "model": "gpt-4",
  "routed_by": "ade",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "Here's a Python function to calculate Fibonacci numbers:\n\n```python\ndef fibonacci(n):\n    if n <= 1:\n        return n\n    return fibonacci(n-1) + fibonacci(n-2)\n```"
      },
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 15,
    "completion_tokens": 58,
    "total_tokens": 73
  }
}

Example: cURL

curl https://api.araviel.ai/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "messages": [
      {
        "role": "user",
        "content": "Explain quantum computing in simple terms"
      }
    ]
  }'

Example: Python

import requests

api_key = "YOUR_API_KEY"
url = "https://api.araviel.ai/v1/chat/completions"

headers = {
    "Authorization": f"Bearer {api_key}",
    "Content-Type": "application/json"
}

data = {
    "messages": [
        {"role": "user", "content": "Explain quantum computing"}
    ],
    "temperature": 0.7
}

response = requests.post(url, headers=headers, json=data)
result = response.json()

print(result["choices"][0]["message"]["content"])

Example: JavaScript (Node.js)

const axios = require('axios');

const apiKey = 'YOUR_API_KEY';
const url = 'https://api.araviel.ai/v1/chat/completions';

const data = {
  messages: [
    { role: 'user', content: 'Explain quantum computing' }
  ],
  temperature: 0.7
};

axios.post(url, data, {
  headers: {
    'Authorization': `Bearer ${apiKey}`,
    'Content-Type': 'application/json'
  }
})
.then(response => {
  console.log(response.data.choices[0].message.content);
})
.catch(error => {
  console.error('Error:', error.response.data);
});

Query Parameters

Parameter Type Description

Streaming Responses

Enable real-time streaming for chat completions using Server-Sent Events (SSE).

Request

{
  "messages": [
    {"role": "user", "content": "Explain AI"}
  ],
  "stream": true
}

Response Stream

data: {"id":"chatcmpl-abc","choices":[{"delta":{"content":"AI"}}]}

data: {"id":"chatcmpl-abc","choices":[{"delta":{"content":" stands"}}]}

data: {"id":"chatcmpl-abc","choices":[{"delta":{"content":" for"}}]}

data: [DONE]

Example: Python

import requests
import json

response = requests.post(
    "https://api.araviel.ai/v1/chat/completions",
    headers={"Authorization": f"Bearer {api_key}"},
    json={"messages": [{"role": "user", "content": "Hello"}], "stream": True},
    stream=True
)

for line in response.iter_lines():
    if line:
        if line.startswith(b'data: '):
            data = line[6:]
            if data == b'[DONE]':
                break
            chunk = json.loads(data)
            content = chunk['choices'][0]['delta'].get('content', '')
            print(content, end='', flush=True)

Error Codes

The API uses standard HTTP status codes and returns error details in JSON format.

Error Response Format

{
  "error": {
    "code": "invalid_request",
    "message": "Missing required parameter: messages",
    "type": "invalid_request_error"
  }
}

HTTP Status Codes

Code Meaning Description
200 OK Request succeeded
400 Bad Request Invalid request parameters
401 Unauthorized Invalid or missing API key
403 Forbidden API key doesn't have required permissions
404 Not Found Resource doesn't exist
429 Too Many Requests Rate limit exceeded
500 Internal Server Error Server error - contact support
503 Service Unavailable Service temporarily unavailable

Error Types

  • invalid_request_error - Malformed request
  • authentication_error - Invalid API key
  • permission_error - Insufficient permissions
  • rate_limit_error - Too many requests
  • model_error - Model unavailable or failed
  • server_error - Internal server error

Official SDKs

We provide official SDKs to make integration easier:

Python SDK

pip install araviel
from araviel import Araviel

client = Araviel(api_key="YOUR_API_KEY")

response = client.chat.completions.create(
    messages=[
        {"role": "user", "content": "Hello, world!"}
    ]
)

print(response.choices[0].message.content)

JavaScript SDK

npm install @araviel/sdk
import Araviel from '@araviel/sdk';

const client = new Araviel({ apiKey: 'YOUR_API_KEY' });

const response = await client.chat.completions.create({
  messages: [{ role: 'user', content: 'Hello, world!' }]
});

console.log(response.choices[0].message.content);
